# Lucas Souza - Minimalist Developer Blog

A clean, minimalist developer blog and portfolio built with Astro, Keystatic, and React. Focuses on core performance, excellent typography, and semantic structure.

## Tech Stack

- **Framework:** [Astro](https://astro.build/)
- **UI:** [React](https://reactjs.org/)
- **Content Management:** [Keystatic](https://keystatic.com/)
- **Styling:** Vanilla CSS (Minimalist, accessible)

## Features

- Fast, static-first rendering
- Markdown/MDX content support
- Clean, semantic HTML structure
- Responsive grid and drawer layouts
- Automated code block copying
- Excellent typography and readability

## Getting Started

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Run the development server:
   ```bash
   pnpm dev
   ```

3. Build for production:
   ```bash
   pnpm build
   ```
