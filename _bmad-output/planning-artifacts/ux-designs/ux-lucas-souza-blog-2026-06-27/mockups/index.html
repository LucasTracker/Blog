Mastering React Query: Um Guia Definitivo de Gerenciamento de Cache

O gerenciamento de estado assíncrono em aplicações React sempre foi um desafio complexo. Tradicionalmente, desenvolvedores utilizavam ferramentas como Redux ou Context API acopladas a useEffects manuais para buscar e guardar dados de API.

O React Query (agora conhecido como TanStack Query) mudou esse paradigma. Ele introduz um modelo declarativo onde as chamadas assíncronas são tratadas como sincronizações de servidor, gerenciando cache, revalidações automáticas e estados de carregamento em background sem esforço.

Como funciona o ciclo de vida do Cache?

Quando você realiza uma consulta através do hook useQuery, o React Query cria uma chave única no cache para armazenar a resposta da API. O ciclo passa por estados importantes:

ReactQueryExample.js
import { useQuery } from '@tanstack/react-query'; function UserProfile({ userId }) { const { data, isLoading, isError } = useQuery({ queryKey: ['user', userId], queryFn: () => fetchUser(userId), staleTime: 1000 * 60 * 5, // 5 minutos de dados considerados 'frescos' gcTime: 1000 * 60 * 30, // Mantém no cache por 30 minutos }); if (isLoading) return

Se a consulta for re-executada enquanto a chave estiver dentro do período de staleTime, o React Query retorna o dado cached imediatamente sem fazer uma nova chamada de rede. Essa estratégia traz um ganho absurdo de velocidade na navegação da aplicação.
