# What are Skills?

It’s very common today to hear the word ***skills*** in the AI universe, but what exactly are they, and what do they do? The answers are right here. So grab your coffee, and let’s dive in!

Skills are essentially folders of instructions, scripts, and resources that give your AI agent the capability to perform tasks more accurately and precisely. They teach your AI agent how to complete specific tasks in a consistent, repeatable way.

The core of a skill consists of one file called `SKILL.md`. This file includes metadata (the name and description) and instructions that tell an agent how to perform a specific task. Skills can also bundle scripts, reference materials, templates, and other resources.

Here is the recommended structure for a skill, based on the agentskill.io website:

```bash
my-skill/
├── [SKILL.md](http://skill.md/)          # Required: metadata + instructions
├── scripts/          # Optional: executable code
├── references/       # Optional: documentation
├── assets/           # Optional: templates, resources
└── ...               # Any additional files or directories
```

As you can see, creating a skill is simple: you just need to set up a new directory and include a `SKILL.md` file inside it! Keep in mind, you can always start with just this single file and add executable scripts or reference documents later as your skill becomes more complex.

## How do Skills Work?

Skills operate through a mechanism known as Progressive Disclosure. In this process, the AI determines which skills are relevant to a given task, loads those skills along with any associated instructions, and executes the task.

Progressive Disclosure can be broken down into three stages:

1. **Discovery** → When your agent starts up, it loads only the name and description of each available skill—just enough to know when it might be relevant.
2. **Activation** → When a task matches a skill’s description, the agent reads the full `SKILL.md` instructions into its context.
3. **Execution** → The agent follows the instructions, optionally executing bundled code or loading referenced files as needed.

### Wrapping Up

Let’s put this into practice by creating a simple skill that makes more detailed Git commits.

The structure for this skill will look like this:

```bash
commit-and-push-skill/
└── [SKILL.md](http://skill.md/)
```

```jsx
---
name: commit-and-push-skill
description: Use this skill when you need to commit and push changes to a repository.
---

# Commit Style
The commit message must include detailed descriptions of the code changes. Do not list the AI agent as the author of the code. Instead, retrieve the developer's name dynamically using Git configuration settings (e.g., `git config user.name`).

## Examples
test.js -> This file contains all unit tests for this project.
main.js -> Added new functionality that allows the system to generate pseudo-numbers with less repetition.
Author: <git config user.name>
Date: Date.Now()
```
